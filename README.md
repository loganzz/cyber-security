# cyber-security

一个以安全学习、漏洞研究与专题笔记整理为主的仓库。当前内容主要分为两类：

- `Bandit`：`OverTheWire Bandit` 靶场闯关题解与命令记录
- `CVE`：按漏洞编号归档的专题分析、材料整理与页面化展示

仓库定位偏向“个人学习沉淀 + 后续持续扩展的知识库”，不是一个可直接运行的业务项目。

## 内容说明

### 1. `Bandit`

`Bandit` 目录当前用于记录 `OverTheWire Bandit` 的闯关过程，现有内容覆盖：

- `Level1`
- `Level2`
- `Level4`

适合用来复盘 Linux 基础命令、文件系统操作、查找过滤与简单管道处理等入门技能。

### 2. `CVE`

`CVE` 目录当前用于沉淀漏洞专题材料。现阶段已包含一个专题：

- [`CVE/CVE-2026-31431/README.md`](CVE/CVE-2026-31431/README.md)：`Copy Fail` 漏洞背景、成因、攻击链路、影响范围、修复与缓解建议
- `CVE/CVE-2026-31431/index.html`：针对该漏洞整理的静态页面版本，便于本地阅读或展示
- `CVE/CVE-2026-31431/copy_fail_exp.py`：当前保留的参考文件，建议后续补充来源说明与内容校验，避免文件名与实际内容产生歧义

从当前内容看，`CVE` 目录更偏向“漏洞研究笔记”和“安全专题整理”，而不是完整的漏洞利用代码仓库。

## 推荐阅读顺序

如果你是从零开始整理这个仓库，建议按下面顺序阅读：

1. 先看 `Bandit`，熟悉基础命令行与 Linux 文件操作思路
2. 再看 `CVE`，进入更系统的漏洞分析、影响评估与缓解方案整理
3. 后续新增专题时，优先保持“一个专题一个目录”的归档方式

## 维护建议

- 新增漏洞专题时，统一使用 `CVE/CVE-YYYY-NNNNN/` 目录格式
- 每个专题至少保留一份 `README.md`，用于说明背景、影响与参考资料
- 若加入 PoC、截图、页面文件，建议补充“来源、用途、可执行性”说明
- 对外部复制而来的文件，建议尽快校验格式与内容，避免出现扩展名与实际内容不一致的问题

## 使用说明

本仓库内容仅适用于学习、研究与授权环境下的安全分析。涉及漏洞原理、利用链路或实验材料时，应确保：

- 仅在合法授权环境内测试
- 不对未授权系统发起验证或利用
- 对可能造成破坏的操作保持审慎
